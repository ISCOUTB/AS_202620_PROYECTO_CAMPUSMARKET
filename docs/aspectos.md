# Aspectos de calidad - CampusMarket

## Aspecto seleccionado: Mantenibilidad

Uno de los principales aspectos de calidad considerados para CampusMarket
es la mantenibilidad.

La plataforma será diseñada mediante una arquitectura modular, buscando
separar las principales responsabilidades del sistema, como la gestión
de usuarios, publicaciones, productos y búsquedas.

Esta separación permitirá realizar modificaciones o agregar nuevas
funcionalidades en el futuro sin tener que modificar completamente
el sistema.

La mantenibilidad será especialmente importante debido a que CampusMarket
podría incorporar posteriormente nuevas funciones, como sistemas de
mensajería, calificaciones de usuarios, favoritos, notificaciones o
métodos de pago.
